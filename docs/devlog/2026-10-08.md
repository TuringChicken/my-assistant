## Decisions
- Async throughout (Ollama AsyncClient + MCP SDK are async).
- MCP tools connect over stdio; `config/mcp_servers.json` uses the Claude Desktop format.
- Build the tool loop first with built-in tools (stage 2), then add MCP (stage 3) —
  debug the two hard parts separately.
- Ollama native tool calling (not prompt-based). Note: tool calling is incompatible with streaming.
- `mcp` is imported lazily, so stages 1-2 run without the MCP package installed.
